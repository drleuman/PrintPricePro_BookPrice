# PrintPrice Pro — Book Price Calculator & Order Orchestration System

> **System Version**: v5.3 "Adversarial Node" Hardened Series  
> **Powered by**: [PrintPrice.Pro](https://printprice.pro) | **Designed by**: [LatinFlash LDA](https://latinflash.com)

A premium, intelligent web application for calculating book printing costs with AI-assisted specification parsing, low-level PDF analysis, and secure multi-printer ordering pipelines. The backend is configured as a hardened Express orchestration layer, preventing API key exposure and enforcing cryptographically secured contracts across all operational boundaries.

---

## 🌟 Key Capabilities

### 🧠 Intelligent Conversational AI Assistant
*   **Natural Language Spec Extraction**: Users can describe a print project in natural language (e.g., *"I want to print 500 copies of a hardcover, 280 pages, colored cover with matte finish and A5 size"*).
*   **Multilingual Semantic Recognition**: Supports heuristics to parse both English and Spanish technical printing terms.
*   **AI Resilience Pipeline**:
    *   **Conflict Protection**: Prioritizes explicit form changes declared by the user over AI guesses.
    *   **Hallucination Remediation**: Modifies conversation text on-the-fly to represent correct system parameters.
    *   **Self-Healing Quotes**: Automatically triggers a recalculation if an AI adjustment invalidates previous offer calculations.

### 📄 Low-Level Client-Side PDF Diagnostics
*   **Automatic Page & Size Ingestion**: Scans local PDF binaries to parse actual page counts, orientations, and page sizes.
*   **Intelligent Size Mapping**: Resolves custom document dimensions to nearest standardized formats (A4, A5, A6, 170x240mm, 200x200mm, etc.).
*   **Color Detection Analysis**: Sample-checks page color coordinates using HTML5 Canvas to flag whether the document is full-color (`4/4`) or monochrome (`1/1`).

### 📦 Dynamic Cart & Cart Gating
*   **Real-Time BPE Integration**: Calculates and aggregates shipping, production, and tax estimates across 25+ countries.
*   **Dual-Path PDF Intake**: Allows customers to directly upload print-ready files or provide authenticated secure storage links.
*   **Stateful Validation Gating**: Blocks checkouts unless both cover and interior PDFs are successfully uploaded, verified, and mapped in the database.

### 🏭 Control Plane & Printer Operations
*   **Secure Dispatch Packages**: Builds isolated manufacturing bundles with secure, self-expiring print-house links.
*   **Stateful Production Queues**: Real-time printer workflow updates (`QUEUED` $\rightarrow$ `REVIEWING` $\rightarrow$ `ACCEPTED` $\rightarrow$ `IN_PREPRESS` $\rightarrow$ `IN_PRODUCTION` $\rightarrow$ `COMPLETED` $\rightarrow$ `SHIPPED`).
*   **Exception & Reupload Pipeline**: Automatically suspends orders if print houses detect layout defects, shifting the client tracking interface to `ACTION_REQUIRED` and enabling direct PDF replacement without creating a new order.

## 🛡️ Advanced Security Architecture (v5.3)

To ensure transaction reliability, the application implements the following security safeguards:

1.  **Anti-Tampering Cryptographic Offer Signatures**: All comparative quotes are verified using HMAC-SHA256 hashes generated by `OFFER_SIGNING_SECRET`. Price, quantity, printer ID, and specs are bound together; any attempt to tamper with prices on the frontend will trigger a verification failure and block cart addition or checkout.
2.  **Anti-Bot Honeypot Shields**: Integrates hidden inputs (`#hp_node`) on forms to trap scraping scripts, dropping automated requests instantly.
3.  **Client Session-Bound Challenges**: Calculations require a prior request to `/api/security/challenge` to obtain a session-bound challenge token and cryptographic nonce, mitigating replay attacks.
4.  **SSRF (Server-Side Request Forgery) Subnet Filtering**: PDF fetch URLs are resolved against IP blacklists, blocking internal loopbacks and private subnet ranges (e.g. `127.0.0.1`, `192.168.x.x`, `10.x.x.x`, `.local` hosts).
5.  **Magic-Byte PDF Binary Verification**: Uploaded files are inspected for `%PDF-` start-of-file headers and `%%EOF` markers, blocking malicious binaries disguised as PDFs.

## 🛢️ Persistence Configurations

PrintPrice Pro v5.3 leverages the **Repository Pattern** to support hot-swapping between flat JSON files (perfect for local testing) and industrial MySQL engines (ideal for multi-node production setups).

Set the adapter in `server/.env` via the `PERSISTENCE_ADAPTER` variable:
*   `json`: Writes to local `/server/storage/` flat files.
*   `mysql`: Connects to your relational instance using automated connection pooling and structured schema deployments.

## 🔌 API Endpoints Reference

### 🛒 Client & Marketplace Endpoints
| Endpoint | Method | Authentication | Description |
| :--- | :--- | :--- | :--- |
| `/api/security/challenge` | `POST` | None | Issues a session-bound cryptographic challenge token |
| `/api/budget/calculate` | `POST` | Bounded Token | Fetches signed BPE pricing quotes |
| `/api/ai/chat` | `POST` | None | Proxies conversational specs parsing to Gemini |
| `/api/cart/add` | `POST` | Session Cookie | Adds cryptographically signed offers to cart |
| `/api/cart` | `GET` | Session Cookie | Lists current cart content |
| `/api/cart/items/:id` | `DELETE` | Session Cookie | Removes item from cart |
| `/api/production-files/upload` | `POST` | Session Cookie | Validates and registers Cover/Interior PDFs |
| `/api/order-intents` | `POST` | Session Cookie | Locks file hashes and registers order intents |
| `/api/order-intents/:id/preflight/start`| `POST`| Session Cookie | Launches automated preflight checks |
| `/api/order-intents/:id/preflight` | `GET` | Session Cookie | Retrieves active preflight metrics |
| `/api/order-intents/:id/billing/create` | `POST` | Session Cookie | Creates invoice structures & Stripe Checkout sessions |
| `/api/orders/:id/tracking` | `GET` | Session Cookie | Generates safe customer order progress timeline |

### 🏭 Printhouse & Management Endpoints
| Endpoint | Method | Authentication | Description |
| :--- | :--- | :--- | :--- |
| `/api/dispatch-packages/:packageId` | `GET` | Dispatch Token | Streams printhouse dispatch package specs |
| `/api/dispatch-packages/:packageId/files/:fileId` | `GET` | Dispatch Token | Streams secure production PDFs to printers |
| `/api/printhouse/queue` | `GET` | Admin / Token | Lists active print assignments |
| `/api/printhouse/queue/:packageId/status` | `POST` | Admin / Token | Advances printer workflow states |
| `/api/order-intents/:id/files/:role/replace` | `POST` | Owner / Admin | Replaces a production file to resolve exceptions |
| `/api/order-intents/:id/exception/review` | `POST` | Admin Only | Resolves or manages operational exceptions |

## ⚙️ Environment Configurations

Create a `.env` file within the `server/` directory:

```env
# Server Details
PORT=3000
NODE_ENV=production

# Secrets & Keys
GEMINI_API_KEY=your_gemini_api_key_here
SESSION_SECRET=your_express_session_secret
SIGNING_SECRET=your_security_challenge_secret
OFFER_SIGNING_SECRET=your_hmac_quote_signing_secret

# Database Adapters (mysql | json)
PERSISTENCE_ADAPTER=mysql
DB_HOST=127.0.0.1
DB_PORT=3306
DB_USER=root
DB_PASSWORD=your_mysql_password
DB_NAME=printpricepro_db

# Control Plane Integrations
CONTROL_PLANE_BASE_URL=https://controlplane.yourdomain.com
CONTROL_PLANE_ORDER_ENDPOINT=/api/v1/orders
CONTROL_PLANE_TOKEN=your_internal_handoff_token

# Stripe Configurations
PAYMENT_PROVIDER=stripe
STRIPE_SECRET_KEY=sk_live_...
STRIPE_WEBHOOK_SECRET=whsec_...
```

## 🚀 Installation & Local Development

### 1. Ingest Dependencies
```bash
# Install frontend packages
npm install

# Install backend packages
cd server
npm install
```

### 2. Prepare Database (If using MySQL)
Ensure your MySQL instance is running and your `.env` variables match. Run the smoke test suite to check connection limits:
```bash
cd server
node scripts/smoke-test-marketplace-mysql.js
```

### 3. Launch Development Server
```bash
# Terminal 1 — Backend (Port 3000)
cd server
npm run dev

# Terminal 2 — Frontend (Vite Client)
npm run dev
```

### 4. Production Compilation
```bash
# Bundle frontend assets to /dist
npm run build

# Preview compilation locally
npm run preview
```
